# Topic Feed

Заметки лентой, как переписка в мессенджере. Топик — это чат, заметки — сообщения.

Плагин для [Obsidian](https://obsidian.md).

## Зачем

Файловое дерево заставляет решать «куда положить заметку» в момент записи — то есть ровно тогда, когда думать надо о мысли, а не о папке. А при поиске оно показывает только имена файлов: чтобы вспомнить, что внутри, каждую надо открыть.

Topic Feed переворачивает порядок: записал не думая, разобрал одним перетаскиванием, нашёл — пролистав ленту, где виден текст, а не имя файла.

Плагин ничего не хранит у себя. Топик — обычная заметка со свойством `type: topic`. Лента — обычные файлы хранилища. Связь — одно свойство `topic` со ссылкой на топик.

## Что умеет

**Проводник** в левом сайдбаре — плоский список папок, топиков и канбан-досок, отсортированный по свежести: топик поднимается наверх, когда правится любая его заметка. Хлебные крошки, создание топика и папки, удаление.

**Лента** — заметка-топик, открытая представлением ленты. Баблы с названием, началом текста и датой правки, свежие внизу. Клик открывает заметку справа — всегда в одной панели, вкладки не плодятся. Бабл открытой заметки подсвечен.

**Разбор** — перетащи бабл на топик в проводнике, и заметка переедет в его ленту. Файл при этом не двигается: меняется одно свойство. Внизу появится уведомление с кнопкой «Отменить».

**Без топика** — отдельная лента всех неразобранных заметок хранилища.

**Множественный выбор** — правый клик по баблу, «Выбрать». Отмеченные заметки можно перенести в один топик или удалить одним действием, с общей отменой.

**Создание** — бабл «Создать заметку» внизу ленты создаёт заметку со связью с этим топиком и открывает её справа с курсором в заголовке.

## Установка

Пока плагина нет в каталоге сообщества, ставится вручную:

1. Скачай `main.js`, `manifest.json` и `styles.css` из [релиза](../../releases).
2. Положи их в `<хранилище>/.obsidian/plugins/topic-feed/`.
3. Перезапусти Obsidian и включи плагин в разделе «Сторонние плагины».

## Настройки

| Параметр | По умолчанию | Что делает |
|---|---|---|
| Длина текста в бабле | 500 символов | Сколько текста заметки видно в ленте |
| Размер текста в бабле | 14px | Ползунок от 11 до 22 |
| Свойство связи | `topic` | Имя свойства, которым заметка привязана к топику |

## Что плагин пишет в заметки

Только свойство связи и только по прямому действию: перетаскиванию бабла или пункту меню. Даты берутся у файла, в свойства не пишутся. Удаление идёт в корзину по настройке хранилища, мимо корзины — никогда. У каждого изменяющего действия есть кнопка «Отменить».

Единственное исключение — удаление папки: оно затрагивает всё её содержимое, поэтому спрашивает подтверждение и отмены не имеет.
