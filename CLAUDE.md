# Topic Feed

Плагин Obsidian: Topic Feed

Что плагин делает — в `docs/SPEC.md`. Текущий этап работ — в `docs/PLAN.md`.
Почему принято то или иное техническое решение — в `docs/DECISIONS.md`.

## Раскладка

- `src/main.ts` — точка входа: команды, подписки. Тонкая.
- `src/lib/` — чистая логика, **не импортирует `obsidian`**. Покрыта тестами.
- `src/settings.ts` — экран настроек.
- `tests/` — Vitest, только на `src/lib/`.

## Команды

```bash
npm run dev      # сборка в ../../vault-test с авто-перезагрузкой
npm test         # тесты
npm run build    # проверка типов + сборка релиза в корень
```
