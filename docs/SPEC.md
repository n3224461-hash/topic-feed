# Спецификация — Topic Feed

## Проблема

Файловое дерево заставляет решать «куда положить заметку» в момент записи — то есть ровно тогда, когда думать надо о мысли, а не о папке. А при поиске оно показывает только имена файлов: чтобы вспомнить, что внутри, каждую надо открыть.

Topic Feed переносит в Obsidian логику мессенджера: **топик — это чат, заметки — сообщения**. Записал не думая, разобрал одним перетаскиванием, нашёл — пролистав ленту, где виден текст, а не имя файла. Плагин ничего не хранит у себя: топик — обычная заметка, лента — обычные файлы хранилища.

## Сценарий использования

1. Записываю мысль как обычно — новая заметка, никаких свойств. Она сразу видна в ленте «Без топика», разбирать её прямо сейчас не нужно.
2. Открываю проводник ленты в левом сайдбаре. Вижу плоский список: папки и топики вперемешку, сверху те, где недавно что-то менялось.
3. Нужен новый топик — ПКМ по пустому месту, «Новый топик», ввожу «Курс вайбкодинг». В текущей папке появляется заметка со свойством `type: topic`.
4. Кликаю по топику — в рабочей области открывается его лента.
5. Разбираю входящие: открываю ленту «Без топика» и тащу бабл влево, на топик в проводнике. Бабл исчезает отсюда и появляется в ленте топика. Внизу — уведомление с кнопкой «Отменить».
6. Топик нужен под рукой — ПКМ по вкладке Obsidian, «Закрепить». Переключаюсь между лентами как между вкладками браузера.
7. Ищу старую мысль — открываю топик и листаю ленту. В каждом бабле начало текста, узнаю заметку по содержанию, а не по имени файла.
8. Кликаю бабл — заметка открывается справа от ленты. Кликаю следующий — он заменяет её в той же панели, вкладки не плодятся.
9. Заметка, которую правил последней, всегда в самом низу ленты. Возвращаюсь к ней, не прокручивая.
10. Заметка попала не в тот топик — ПКМ по баблу, «Переместить в топик», выбираю нужный из списка.
11. Заметка не нужна — ПКМ, «Удалить». Уходит в корзину, внизу уведомление с «Отменить».
12. Переименовываю топик — ссылки в заметках обновляет сам Obsidian, лента остаётся целой.

## Что делает

**Проводник — панель в левом сайдбаре со своей иконкой**

- Показывает плоским списком папки и топики одного уровня, вперемешку.
- Сортирует по свежести: топик поднимается, когда правится или создаётся любая его заметка; папка — по самому свежему топику внутри, включая вложенные.
- Клик по папке проваливается внутрь, вверху появляются хлебные крошки.
- Клик по топику открывает его ленту в рабочей области.
- Видны только папки, внутри которых есть топики или доски. Пустые для ленты папки не показываются.
- ПКМ по строке: «Удалить». Топик и доска уходят в корзину с возможностью отмены; папка — только после подтверждения, вместе со всем содержимым.
- Показывает канбан-доски соседнего плагина наравне с топиками: со своей иконкой и числом задач. Клик открывает доску. Для фильтра доска считается так же, как топик — папка с одной только доской видна.
- Служит целью для перетаскивания баблов из ленты. Папка и доска бабл не принимают и показывают курсор запрета.

**Лента — вкладка рабочей области**

- Заметка со свойством `type: topic` открывается лентой — откуда бы её ни открыли: из проводника ленты, из файлового дерева, из поиска, по ссылке.
- Вверху — шапка с собственным текстом заметки-топика.
- Бабл: заголовок, начало текста, дата и время последней правки в углу. При наведении — подсказка с датой создания.
- Высота бабла считается по содержимому.
- Порядок — по дате последней правки, свежие внизу. Лента открывается прокрученной вниз.
- Остальные баблы подгружаются порциями при прокрутке вверх.
- Клик по баблу открывает заметку в панели справа от ленты — всегда в одной и той же, новые сплиты не создаются. Бабл открытой заметки подсвечен, пока она остаётся в этой панели.
- ПКМ по баблу: «Выбрать», «Переместить в топик», «Переименовать», «Скопировать ссылку», «Удалить».
- «Выбрать» включает режим выделения: слева от каждого бабла появляются кружки-отметки, клик по баблу переключает выбор вместо открытия заметки. Внизу вместо бабла создания — панель «Выбрано: N» с действиями «Переместить в топик» и «Удалить». Когда снят последний выбор, отметки исчезают и лента ведёт себя как обычно.
- В самом низу ленты — пустой бабл «Создать заметку». Клик создаёт заметку и открывает её справа, там же, где открываются остальные. Заметка топика ложится в его папку и сразу получает связь; заметка из «Без топика» — в папку для новых заметок Obsidian.
- Отдельная лента «Без топика» — команда в палитре и иконка на панели. Показывает все заметки хранилища без свойства связи. Топики и доски в неё не попадают: это контейнеры, а не заметки. Закрепляется вкладкой так же, как любой топик.

**Связь заметки с топиком**

- Заметка принадлежит топику через свойство `topic` со ссылкой на заметку-топик.
- Перетаскивание бабла на топик меняет только это свойство. Файл остаётся там, где лежал.
- У заметки один топик: новая связь заменяет прежнюю, бабл исчезает из старой ленты.

## Чего не делает

- Не перемещает, не переименовывает и не сортирует файлы при организации — только правит свойство.
- Не проставляет свойства заметкам, которых пользователь не трогал.
- Не хранит даты в свойствах — берёт время создания и правки у самого файла.
- Не пишет заметки за пользователя: поля ввода с текстом в ленте нет, новая заметка создаётся пустой и наполняется в обычном редакторе Obsidian.
- Нет ИИ-агента и диалогов в ленте.
- Нет поиска — ни по ленте, ни по проводнику.
- Не показывает картинки и вложения в превью, только текст.
- Не поддерживает несколько топиков у одной заметки.
- Не адаптирован под мобильный Obsidian.
- Не заменяет файловое дерево и не прячет его — работает рядом.
- Не создаёт канбан-доски и не редактирует их содержимое: только показывает их в проводнике, открывает и умеет удалить как обычную заметку. Всё остальное — работа плагина kanban-notes.

## Настройки

| Параметр | По умолчанию | Зачем |
|---|---|---|
| Длина текста в бабле | 500 символов | Короче — лента плотнее и быстрее листается, длиннее — меньше поводов открывать заметку |
| Размер текста в бабле | 14px | Ползунок от 11 до 22: лента подстраивается под зрение и под ширину панели |
| Свойство связи | `topic` | Если в хранилище уже принято другое слово для той же связи, менять заметки не придётся |

## Готово, когда

- В левом сайдбаре есть панель со своей иконкой; в ней плоский список папок и топиков текущего уровня.
- Заметка со свойством `type: topic` при открытии показывается лентой, а не текстом, — из проводника ленты и из файлового дерева одинаково.
- В ленте топика видны все заметки хранилища со свойством `topic`, ссылающимся на этот топик, и только они.
- Баблы идут по дате последней правки, свежие внизу; после правки заметки её бабл оказывается последним.
- На бабле видны заголовок, первые 500 символов текста без служебных свойств и дата последней правки; при наведении — подсказка с датой создания.
- Клик по баблу открывает заметку в панели справа от ленты; второй клик по другому баблу заменяет содержимое той же панели.
- Перетаскивание бабла на топик в проводнике меняет свойство `topic` в файле заметки, бабл исчезает из прежней ленты и появляется в новой.
- После перетаскивания и после удаления показывается уведомление с кнопкой «Отменить», и она возвращает прежнее состояние.
- «Удалить» в меню бабла отправляет файл в корзину по настройке хранилища.
- ПКМ в проводнике создаёт папку и заметку-топик со свойством `type: topic` в текущей папке.
- Топик, в заметке которого только что правился текст, оказывается вверху проводника; папка с ним поднимается целиком.
- В проводнике не видны папки, внутри которых нет ни топиков, ни досок.
- Команда «Лента: без топика» открывает ленту всех заметок хранилища без свойства связи; заметки-топики и заметки-доски в ней не показываются.
- Заметка со свойством `type: kanban` видна в проводнике с иконкой канбана и числом своих задач; клик по ней открывает доску, строка подсвечивается как активная.
- Папка, внутри которой есть только доска и ни одного топика, в проводнике видна.
- При перетаскивании бабла на папку или на доску курсор показывает запрет, отпускание ничего не меняет.
- ПКМ по строке проводника предлагает «Удалить»: топик и доска уходят в корзину с кнопкой «Отменить», папка — только после подтверждения, в котором названо число файлов внутри.
- Клик по баблу «Создать заметку» внизу ленты создаёт пустую заметку со связью с этим топиком и открывает её справа готовой к набору текста.
- Пункт «Выбрать» в меню бабла показывает отметки у всех баблов; отметив несколько, можно переместить их в один топик или удалить одним действием с общей кнопкой «Отменить».
- В ленте на 1000 заметок сначала отрисовывается только видимая часть, остальное подгружается при прокрутке вверх.
- Изменение заметки или свойства вне плагина обновляет открытую ленту без перезапуска Obsidian.

## Риски для данных

Плагин пишет в чужие заметки в трёх случаях, все — по прямому действию пользователя.

- **Смена топика** (перетаскивание бабла, «Переместить в топик», «Убрать топик»): меняется значение единственного свойства `topic`. Остальные свойства, текст заметки и её расположение не трогаются.
- **Удаление** («Удалить» в меню бабла или в меню строки проводника): файл отправляется в корзину по настройке хранилища — системную или папку `.trash`. Мимо корзины плагин не удаляет никогда.
- **Удаление папки** («Удалить» в меню папки в проводнике): в корзину уходит папка со всем содержимым. Это единственное действие плагина, которое затрагивает больше одной заметки, поэтому оно всегда спрашивает подтверждение и называет число файлов внутри. Отмены у него нет — восстанавливать дерево файлов плагин не умеет.
- **Переименование** («Переименовать» в меню бабла): файл получает новое имя в той же папке. Ссылки на него в других заметках обновляет сам Obsidian — по своей настройке «Автоматически обновлять внутренние ссылки», ровно так же, как при переименовании из файлового дерева. Плагин в чужие заметки при этом не пишет, но изменить их может Obsidian.

Защита:

- После каждой из этих операций внизу появляется уведомление с кнопкой «Отменить», живущее несколько секунд. Отмена возвращает прежнее значение свойства, прежнее имя файла или восстанавливает удалённую заметку.
- Живое уведомление всегда одно: новое действие гасит предыдущее, чтобы старая кнопка не откатила заметку через голову новой.
- Отмена удаления создаёт файл заново по прежнему пути с прежним содержимым — вместе с папкой, если её успели удалить. Даты создания и правки при этом начинаются заново: восстановленный файл для файловой системы новый. Сам удалённый файл остаётся в корзине в любом случае.
- Групповые действия из режима выделения затрагивают ровно те заметки, что отмечены. Групповое перемещение спрашивает топик один раз и меняет у каждой заметки единственное свойство связи; групповое удаление сначала спрашивает подтверждение с числом заметок. У обоих одна кнопка «Отменить» на всю группу — она возвращает все заметки разом.
- Удаление папки — единственное действие, у которого отмены нет: восстанавливать дерево файлов плагин не умеет, поэтому оно закрыто подтверждением.
- Создание папки, топика и заметки создаёт новые файлы и не трогает существующие: имя, если занято, получает числовой суффикс.
- Всё остальное — сортировка, закрепление, прокрутка — только чтение.
