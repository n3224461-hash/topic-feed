# Технические решения — Topic Feed

Записываются только решения, которые дорого менять потом: структура данных, формат хранения настроек, внешние зависимости, способ работы с заметками.

Выбор имени переменной сюда не пишем.

Формат записи:

```
## 2026-08-18 — Настройки храним в data.json, а не в отдельной заметке
**Выбрали:** стандартный saveData/loadData
**Почему:** переживает синхронизацию и не засоряет хранилище пользователя
**Отвергли:** заметку в vault — её легко удалить или переименовать вручную
```
